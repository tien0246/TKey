# TKey

Bộ gõ tiếng Việt cho macOS (Liquid Glass — macOS 26+).

- **Kiểu gõ:** Telex, VNI, VIQR, Simple Telex
- **Bảng mã:** Unicode, Unicode tổ hợp, TCVN3, VNI Windows, CP1258, VIQR
- **Tính năng:** Kiểm tra chính tả, khôi phục từ tiếng Anh, gõ tắt, chuyển mã, loại trừ ứng dụng

## Build

```sh
./build.sh
cp -R TKey.app /Applications/
```

## Test

```sh
zsh Tests/run_tests.sh
```
